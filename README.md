# ביטיפוש · BTPush

<img src="store/icon.png" width="96" align="left" alt="">

אפליקציה לנגן אופליין, בעיצוב של ערוצי טלגרם: המחשב מתחבר לנגן בבלוטות' ושולח אליו חדשות והתראות. כל מקור הוא ערוץ משלו, וכל עדכון חדש יכול לקפוץ כפוש.

<br clear="left">

## הורדה

- **האפליקציה לנגן:** [BTPush.apk](https://github.com/Xnet2/btpush/releases/latest/download/BTPush.apk)
- **התוכנה למחשב (Windows):** [BTPush-PC.zip](https://github.com/Xnet2/btpush/releases/latest/download/BTPush-PC.zip)

## מה מגיע

- **הגיזרה** ([hagizra.news](https://hagizra.news/)): כל ידיעה חדשה.
- **אותנטי** ([authenti.newsupdates.click](https://authenti.newsupdates.click/)): כל מבזק חדש, וכל ערוץ של אותנטי הוא ערוץ נפרד.
- **התראות המחשב**: כל התראה שקופצת ב-Windows (וואטסאפ, Chrome, מייל וכו'), וכל תוכנה היא ערוץ נפרד.

## מה יש בה

- רשימת ערוצים כמו בטלגרם: לוגו, העדכון האחרון, שעה ומונה של מה שלא נקרא, עם תיקיות (הכל, הגיזרה, אותנטי, מחשב)
- מסך ערוץ עם בועות הודעה, תאריכים ולחיצה ארוכה להעתקה
- פושים לבחירה: מתג כללי, והשתקה לכל ערוץ. ערוץ מושתק ממשיך לקבל עדכונים בלי להקפיץ פוש
- חיפוש בערוצים ובהודעות
- שאיבה: מכל ערוץ, גם כזה שעוד לא הגיע אליו כלום, אפשר למשוך עד 3 ימים אחורה: הודעות, הודעות ותמונות, או רק תמונות להודעות שכבר בערוץ
- תמונות לפי בקשה: בהודעה עם תמונה יש כפתור "טעינת תמונה", והמחשב מוריד, מקטין ושולח. התמונות מופיעות מתחת לטקסט בפינות מעוגלות, ונפתחות במסך מלא על רקע מטושטש
- חלוניות מעוצבות שעולות מלמטה (בלי חלונות מערכת), עם לוגו לכל ערוץ ברשימות הבחירה
- שמירת עדכונים לבחירה (משעה ועד חודש אחורה), צליל ורטט, ובחירת ערוצים ותוכנות
- עובד עם נטפרי, על אנדרואיד 4.4 ומעלה. התוכנה למחשב רצה על Windows 10/11 בלי התקנה

## התקנה

1. **שיוך:** מפעילים בלוטות' בנגן ובמחשב. במחשב: הגדרות ← Bluetooth ומכשירים ← הוספת מכשיר, ובוחרים את הנגן. (אם הנגן לא מופיע: באפליקציה, הגדרות ← חיבור למחשב ← "להפוך את הנגן לגלוי לשיוך").
2. **בנגן:** מעתיקים את `BTPush.apk` לנגן, מתקינים ופותחים פעם אחת. מעכשיו היא רצה ברקע, גם אחרי כיבוי והדלקה.
3. **במחשב:** לוחצים לחיצה ימנית על `BTPush-PC.zip` ← "חלץ הכל", ומפעילים את `BTPush.exe` מהתיקייה שנוצרה (לא ישר מתוך ה-ZIP). בהפעלה הראשונה התוכנה שואלת אם להפעיל אותה עם כל הדלקה של המחשב. היא נכנסת לאזור ההתראות שליד השעון ומוצאת את הנגן לבד, או שבוחרים אותו ברשימה "הנגן:".

כשהחיבור מצליח, בחלון במחשב כתוב "מחובר לנגן", ובאפליקציה מופיעה נקודה ירוקה.

**אם האנטי-וירוס של Windows חוסם את התוכנה:** התוכנה חדשה ואין לה חתימה דיגיטלית בתשלום, ולכן Windows עלול לחשוד בה. זו התרעת שווא. הקוד כולו פתוח כאן בריפו. כדי לאשר אותה: אבטחת Windows ← הגנה מפני וירוסים ואיומים ← היסטוריית הגנה ← בוחרים את הפריט ← פעולות ← "אפשר במכשיר".

## איך זה עובד

- המחשב בודק את האתרים דרך ממשקי הנתונים שלהם (`/api/v3/messages` בהגיזרה, `get_messages_optimized.php` באותנטי), ומנקה את הטקסט מסימני עיצוב.
- את התראות Windows התוכנה קוראת מעותק של מסד ההתראות של המערכת (`wpndatabase.db`), בלי לגעת בקובץ המקורי.
- החיבור הוא בלוטות' RFCOMM: הנגן מחכה לחיבור, והמחשב מתחבר אליו. כל עדכון נשלח כשורת JSON. ההגדרות שבנגן נשלחות למחשב בכל חיבור, כך שהמחשב לא שולח את מה שכבוי.
- תמונות לא נשלחות מראש: הנגן מבקש תמונה, והמחשב מוריד אותה, מקטין ל-720 פיקסלים ושולח (בדרך כלל 20–50 KB).
- אם החיבור נפל, המחשב שומר את מה שלא נשלח (עד 30 דקות) ושולח כשהנגן חוזר.

## בנייה

```powershell
powershell -ExecutionPolicy Bypass -File android\build.ps1
powershell -ExecutionPolicy Bypass -File pc\build.ps1
```

הנגן נבנה עם ה-JDK וה-SDK שב-`%LOCALAPPDATA%\VODOS-build`, והמחשב עם `csc` של ‎.NET Framework שמגיע עם Windows.
